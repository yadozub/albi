# Historia Albigensium — перевод и комментарий

> *Non studuerim superfluis verbis ornare codicem,*
> *sed simplicem exprimere simpliciter veritatem.*
>
> «Не старался я излишними словами украсить книгу,
> но простую истину выразить просто».
>
> — брат П., монах Во-де-Сернэ, из пролога к Иннокентию III (стр. 24)

Проект перевода и научного комментирования средневековой латинской хроники **Петра де Сернэ** (*Petrus Vallium Sarnaii, Historia Albigensium*, ок. 1212–1218) по печатному изданию **Никола Камюза** (Труа, 1615). Русский перевод — параллельно с латынью, с историко-критическим аппаратом.

**Источник:** [`albi.pdf`](albi.pdf) — скан издания Камюза 1615 (*Historia Albigensivm… TRECIS… M.VI.C.XV*), 379 стр., с текстовым слоем OCR.

## Конвенции

- **Транскрипция** — с сохранением орфографии оригинала: тиронские знаки (`⁹`=`-us`), макроны (=опущенный `n`/`m`), лигатуры `æ`/`œ`, длинная `ſ` передаётся как `s`, `u/v` по оригиналу.
- **Перевод** — параллельный (латынь ‖ русский), с сохранением барочного регистра Камюза; пояснения — в сносках под каждой страницей.
- **Разметка достоверности** в аппарате: ✅ документировано · ◐ вероятно · ⚠ под вопросом.
- **Реалии сверяются** по внешним источникам и критическим изданиям; расхождения издания Камюза 1615 с оригиналами отмечаются отдельно.

## Метод чтения оригинала
Страница `albi.pdf` рендерится в PNG (PyMuPDF, 300 dpi) и читается визуально — транскрипция идёт с изображения, а не с OCR.

## Состав
- **Арка I** — предисловие Камюза (стр. 1–9): параллельный текст латынь ‖ русский с приложениями.
- **Арка II** — раздел *Excerpta* (стр. 9–22), завершена: шесть выдержек — Роберт Осерский, Гуго, Цезарий Гейстербахский, Матфей Парижский, Науклер, Папир Массон.
- Тело хроники Петра де Сернэ (Prologus, стр. 23+) — в работе.
